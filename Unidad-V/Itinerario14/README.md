### Guía de preguntas de repaso conceptual

1. ¿Qué es una expresión Lambda?
2. Ejemplifique cómo se puede utilizar una expresión lambda para realizar una consulta.
3. ¿Qué debo realizar para crear una expresión lambda?
4. ¿Indique como puede declarar un delegado utilizando Func y que significa cada elemento utilizado?
5. Crear  un  delegado  utilizando  Func  que  posea  tres  parámetros  de entrada y uno de salida.
Los parámetros de entrada son: el primero int, el segundo double y el tercero bool. El parámetro de retorno es de tipo bool.
